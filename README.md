# 鞋料用量计算 · 排料估算

面向鞋厂的网页小工具：读取鞋类配料 DXF，按尺码和双数计算裁片用料、换算 45 m 卷数，并给出排料示意图。

- **纯前端**：无需安装、无需联网，双击 `index.html` 即可使用。
- **内置示例**：已从 `24AWB5308-2 (8).DXF` 中提取 31–38 码、10 个配件的数据；也可以导入其它 DXF。
- **按尺码核算**：每个尺码单独填数量，单码、多码组合都能汇总。
- **可视排料**：横排 + 每个配件可选的交错方式，画布可缩放/拖动，右侧缩略条查看整卷分布。

## 快速开始

方式一：直接双击 `index.html`（Chrome / Edge / Firefox 等现代浏览器）。

方式二：起一个静态服务器（可选）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 程序是纯静态网页，**运行不需要 Python/Node**；只要浏览器即可。

## 使用流程

1. 在「订单数量」里填写每个尺码要做的**双数**（留空或 0 表示不做）。
2. 按图纸情况设置「每双片数」：
   - `1 片 / 双`：默认值，每个配件每双用 1 片；
   - `2 片（左右脚）`：图纸只画了一只鞋的裁片时使用，一双需要左右各一片。
3. 按坯布实际宽度选择「坯布幅宽」：1.35–1.40 m，每 0.01 m 一挡，默认 1.40 m；系统自动扣除两边各 15 mm 布边，得到有效幅宽（默认 1370 mm）。
4. 需要时调整「裁片间距」；在「配件清单」的「交错排版」列给每个配件选择：
   - **默认**：相邻片 180° 翻转（原先的交错套排逻辑）；
   - **左右交错**：相邻片左右翻转；
   - **上下交错**：相邻片上下翻转；
   - **不交错**：同向直排，用料更保守。
   处理顺序是先按「方向」旋转裁片，再应用交错方式。
5. 在「配件清单」里用 `− / +` 设置每个配件的每双用量（例如某个配件一双要 2 份），名称可以直接改。
   每行的「方向」可用 `↺ / ↻` 按 45° 步进调整该配件的排放方向（0–315°），点击角度值恢复「自动」；
   自动模式会在 0°/90° 中择优，手动设置后该配件只按指定方向排料。
6. 查看结果：
   - **预计排料长度**、**份数（45 m/份）**、**备料长度**、**排料利用率**；
   - **估算区间**：交错排版 ~ 全部直排保守；
   - 「尺码汇总」按尺码拆分片数、面积、米数。
7. 「导出 CSV」留档；「示例订单」一键填入 31 码 5000 双、32 码 6000 双。

### 尺码设置

- 尺码标签可直接编辑（如 25、26…）。
- 「+ 添加尺码」会在末尾增加一个尺码，按上一码的比例推算裁片（行内会有橙色小点标记），数量默认 0。
- 「批量重编号」可以把当前所有尺码重新编号为连续的号码，例如把 31–38 改成 25–32。
- 每行最右侧 `×` 删除该尺码。

### 导入其它 DXF

- 支持 `POLYLINE` / `LWPOLYLINE`（含圆弧凸度）绘制的**闭合轮廓**。
- 识别规则：闭合（首尾距离 ≤ 1 mm）→ 面积 ≥ 250 mm² → 剔除被更大轮廓包住的内部工艺线 → 按包围盒上边缘分行（配件） → 行内按 x 从左到右排序（尺码）。
- 若两组不同配件并排画在同一高度（上边缘接近，会被聚成一行），会按 x 方向的大间隙自动拆分为多个配件，避免配件丢失。
- 尺码标签默认从 31 开始，可用「批量重编号」改成实际尺码。
- 导入的文件只保存在当前页面，刷新后会回到示例数据；请用 CSV 存档。

## 计算模型

已知条件：**坯布幅宽 1.35–1.40 m 可设（每 0.01 m 一挡，默认 1.40 m），每份长 45 m**；布边每边扣 15 mm，
**有效幅宽 = 坯布幅宽 − 30 mm**（默认 1.40 m 时为 1370 mm）；图形单位 mm，外轮廓为净样；裁片可旋转、翻转。
裁片间距默认 3 mm，最低 2 mm（适合工业生产），排料结果经过精确几何校验，严格不重叠。

计算步骤：

1. 片数 = 双数 × 每双用量 × 每双片数。
2. 每个「配件 × 尺码」单独排料：
   - 直排：每排片数 = ⌊(有效幅宽 + 间距) ÷ (片宽 + 间距)⌋；
   - 交错排版：相邻片交替翻转后，**分别求 A→B、B→A 两个方向的最小排距**（两者可以不同），
     再按 A、B 交替的累计位置摆放；排距先用 2 mm 栅格估算，再用**精确多边形距离**校验
     （相交、包含、顶点到边的最小距离），并校验隔片 A-A / B-B 关系；
     每排片数以累计宽度不超过有效幅宽为准。这样可避免“固定排距”在一侧留下大片空隙，
     特别适合有一角突出的裁片；
   - 方向：默认同时尝试 0°/90° 取用料最少的方案；在配件清单里手动设置方向后，只按该方向排料。
   - 交错方式：先按方向旋转，再按所选方式生成相邻片（默认 180°、左右翻转、上下翻转、不交错）。
3. 排数 = ⌈片数 ÷ 每排片数⌉；
   单组长度 = 排数 × 排高 + (排数 − 1) × 间距。
   校验覆盖整排 A-B-A-B 交替的所有相邻关系（含隔片、隔两片，直到包围盒拉开）
   以及排与排之间的间距，保证**任意两片不重叠**、片间最小距离 ≥ 裁片间距。
4. 各组依次沿布长排列，满 45 m 换卷；卷尾剩余计为余料。
5. 份数 = 卷数；备料长度 = 份数 × 45 m。
6. 利用率 = 裁片总面积 ÷ (有效幅宽 × 净排料长度)。
7. 估算区间：下限为按各配件交错设置的结果，上限为全部直排的保守结果；另给出按面积计算的理论下限。

> 这是可解释的工程估算，不追求数学最优。实际生产请以 CAD 排料结果为准。

## 目录结构

```
index.html              页面
assets/styles.css       样式
js/dxf.js               DXF 解析 + 裁片/尺码识别（浏览器端，也用于导入）
js/nesting.js           排料引擎（横排 + 交错排版 + 45° 方向 + 卷材模拟）
js/app.js               界面、状态、可视化和导出
data/parts.js           内置示例数据（由 DXF 提取）
tools/extract_parts.py  从 DXF 生成 data/parts.js
24AWB5308-2 (8).DXF     原始图纸
```

## 重新生成内置数据

```bash
python tools/extract_parts.py "24AWB5308-2 (8).DXF"
```

脚本会输出识别到的行数/尺码数，并覆盖 `data/parts.js`。图形会做 0.15 mm 的抽稀，面积误差可忽略。

## 已知限制

- 只识别闭合多段线；由散线（LINE/ARC）拼出来的轮廓不支持。
- 方向按 45° 步进设置（0–315°）；未设置时为自动 0°/90°。不支持非 45° 倍数的任意角度。
- 方向按配件设置，作用于该配件的所有尺码；不支持单个尺码单独设置方向。
- 依赖「一行配件、一列尺码」的图纸布局；若图纸排布不同，识别结果会不准（并排配件会按间隙拆分）。
- 每双片数按整体生效；方向、交错方式按配件设置（作用于该配件的所有尺码）。
- 上传的 DXF 不做持久化，刷新后恢复示例数据。
- 工具给出估算值，不替代专业排料软件。
